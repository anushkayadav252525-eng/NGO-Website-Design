# 🌿 NGO Website - Feature Highlight

A responsive and user-friendly web interface designed for non-profit organizations. Built using clean **HTML5, CSS3, and JavaScript**, based on a Figma UI design.

### ✨ Key Features:
* 💝 **Donation Section:** High-visibility call-to-action for immediate support.
* 📊 **Impact Showcase:** Key statistics on meals, education, and volunteer outreach.
* 📅 **Campaigns & Events:** Interactive cards highlighting active community drives.
* 🤝 **Volunteer Form:** Simple onboarding form for new volunteers.
* 💬 **Testimonials:** Supporting feedback from community members.
* 📞 **Contact & Support:** Clear contact details and location info.

### 🛠️ Tech Stack:
* **Design:** Figma
* **Frontend:** HTML5, CSS3, JavaScript
* **Deployment:** GitHub Pages
